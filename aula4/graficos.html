Gráficos: Canvas e SVG

1. Canvas

O <canvas> é uma "tela em branco" que só ganha desenho através de JavaScript. Ele não guarda os objetos desenhados — é só pixels. Se você quiser mover uma forma depois de desenhada, precisa apagar tudo e desenhar de novo.

2. SVG

O SVG é feito de "elementos" de verdade (como <rect>, <circle>), parecido com HTML. Cada forma continua existindo depois de desenhada, então dá pra estilizar com CSS e até animar sem precisar redesenhar tudo.

3. Quando usar cada um?

O Canvas funciona bem para desenhos que mudam com frequência e têm muitos elementos ao mesmo tempo, como jogos, animações complexas ou gráficos gerados a partir de grandes volumes de dados — porque ele desenha pixels diretamente, sem manter uma estrutura de objetos na memória. Já o SVG é mais indicado quando o desenho é composto por poucas formas que precisam continuar "vivas" depois de desenhadas — por exemplo, ícones, logotipos, gráficos estáticos ou interativos onde cada forma pode receber estilo em CSS, eventos de clique ou ser redimensionada sem perder qualidade, já que é um formato vetorial.
